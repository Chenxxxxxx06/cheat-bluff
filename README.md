## 这是什么？

一个面向 Windows 的本地面试工作台。把简历、论文、代码和项目笔记整理成自己的知识库，再围绕具体岗位准备、练习和复盘。

我想做的是一个用着顺手、看着清爽的工具：资料放得下，项目讲得清，面试过后还能知道下一次该改什么。

| 准备之前 | 准备过程中 | 面试之后 |
| --- | --- | --- |
| 整理简历、论文、代码和笔记 | 补充公司、岗位和 JD，练习项目问答 | 按时间线回看记录，补充复盘 |
| 知识卡保留原文依据 | 结合自己的材料组织回答 | 用关键词或 `Ctrl+F` 找回内容 |

- **自己的知识库**：材料、知识卡和个人贡献分开整理，方便核对出处。
- **简洁的工作台**：统一控件、深浅主题、跟随系统，左右分栏可拖动。
- **从空白开始**：新对话有简短步骤；准备档案可命名，记录可删除和恢复。
- **按需接入模型**：使用者自行配置连接；支持兼容的文本、图片和向量服务。实时语音另有协议要求。
- **本地保存**：档案、材料和记录留在本机；使用云端模型时，相关输入会发送给你配置的服务。

> 这是干净的公开版：不附带作者的密钥、账号、知识库、简历或面试记录，也不提供共享额度。首页截图来自全新的空档案。无需模型连接即可浏览界面、管理材料；AI 回答需要自行配置。

## 开始使用

目前提供源码版本，需要 **Windows、Node.js 24 和 npm**。

```bash
git clone https://github.com/Chenxxxxxx06/cheat-bluff.git
cd cheat-bluff
npm ci
npm start
```

第一次打开：

1. **建立自己的资料库**：在“个人资料与知识库”中新建档案，导入自己的简历和项目材料。
2. **配置模型（按需）**：打开“AI 与本地数据”，填写自己的服务地址、模型名称和凭据，再测试连接。不要直接沿用占位地址。
3. **准备一场面试**：创建档案，写下公司、岗位和 JD，再选择关联材料。
4. **练习与复盘**：梳理项目介绍和追问；之后在面试记录中搜索、修改名称、补充笔记。

纯文本 PDF、Office 文档、代码和文本材料可以直接导入。扫描件识别需要另行准备本地 OCR 运行时和模型，当前仓库不捆绑这些大文件。实时转写使用 DashScope WebSocket 协议，普通文本模型连接不一定支持语音。

本机数据独立保存在 `%APPDATA%/CheatBluff/`。**公开版不会读取作者的旧版资料目录，也不会读取其他 AI 软件的登录凭据。**

<details>
<summary>开发、检查与打包</summary>

```bash
npm test
npm run verify:public
npm run package:dir
```

`out/` 是当前可运行的应用代码，`test/` 包含公开版回归测试。打包输出位于 `dist/`，不会随源码提交。依赖首次安装需要联网；模型连接和本地 OCR 组件需由使用者自行准备。

## 搭配一份中文简历

先把经历写清楚，再练习怎么讲。可以搭配这个独立模板使用：

**[Chinese Resume LaTeX · 个人中文简历模板](https://github.com/Chenxxxxxx06/chinese-resume-latex)**

模板提供中文排版、项目条目、可点击链接与 logo 插槽。修改内容后，用 **XeLaTeX** 编译，或导入 Overleaf 并选择 XeLaTeX；生成的 PDF 可以作为自己的简历导入 Cheat Bluff。这里提供模板入口，不会导入任何人的真实简历。

也建议大家学一下阿酥：**给自己的项目简单画一个 logo，再放进 LaTeX 简历里。** 不用画得复杂，轮廓清楚、缩小后认得出来就很好。图片放进模板的 `assets/`，例如：

```latex
\projectentry[assets/project-logo.png]
  {你的项目名称}{你的角色}{技术栈或一句话介绍}
```

项目 logo 的统一尺寸、矢量导出和简历排版示例，后面会继续研究补上。
