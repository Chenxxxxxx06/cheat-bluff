# Source provenance / 来源说明

Cheat Bluff contains original modifications built on a recovered application distribution. The runnable renderer is in `out/renderer/assets/index-D53zCVi_.js`; a full original source tree is not available.

The screenshot-guided desktop shell and new local workflow modules were implemented for this project. No Codex service credentials or Codex source code are included. The public edition uses its own local data namespace, ships no personal corpus, and removes adapters that read other applications' credentials.

The provenance and redistribution permissions of the recovered code, the audio sidecar binary and some historical assets are not fully documented. Public availability does not resolve those records or imply a blanket MIT license. Existing third-party notices remain applicable. If you own relevant rights or can help complete these records, please open an issue.
