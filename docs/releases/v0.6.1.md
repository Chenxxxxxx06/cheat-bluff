# Cheat Bluff 0.6.1

更清爽的连接设置，更自然的面试练习。

**Windows 用户下载 `Cheat-Bluff-Setup-0.6.1-x64.exe`，双击安装。** 已包含应用运行环境、音频组件和本地 OCR，无需安装 Node.js 或 Python。

## 这次更新

- 重新整理模型设置：分组表单、统一控件和深浅配色。
- 优化口述回答：优先讲重点，多问分开回答，减少生硬的材料复述。
- 修复通用知识问题误关联项目，以及未经确认就声称用户做过某项工作的情况。
- 修复普通上传资料没有项目标签时的检索问题；重新导入变化文件后，旧知识卡失效并可重新提炼。

## 从自己的资料开始

公开版初始知识库、准备档案和面试记录均为空，不包含作者的个人项目、简历、密钥或模型连接配置。打开 **AI 与本地数据**，填写自己的服务地址、密钥和模型，再导入自己的 PDF、DOCX、代码或笔记。

材料导入本身不调用云端模型；AI 精炼和回答会使用你配置的服务。实时语音转写需要兼容 DashScope WebSocket 的配置，不是所有聊天模型连接都支持语音。软件不提供共享额度。

## 发布检查

- 63 项公开版测试通过，包括合成 DOCX／PDF／代码的导入、检索和更新流程；模型部分使用测试替身。
- 878 个应用运行文件与源码逐字节一致；安装包解出的 13,813 个文件与已检查的构建产物校验一致。
- 安装包内容、默认配置及首次启动检查通过：无个人资料、无密钥、无预设连接。
- 从安装包解出的应用独立启动成功；首页和模型设置已查看，本地 OCR 实际识别了中文扫描 PDF。

本次未测试安装向导覆盖既有安装，也未使用作者凭据进行云端模型或实时语音测试。下载后需自行配置服务。应用不会自动清空已有用户数据。

适用于 **Windows 10 / 11 x64**。安装包尚未使用受信任证书签名，Windows 可能显示“未知发布者”。随附 `SHA256SUMS.txt` 供校验。

## English

**Download `Cheat-Bluff-Setup-0.6.1-x64.exe` and run it.** The Windows x64 installer includes the application runtime, audio component and local OCR. No Node.js or Python setup is required.

### What's new

- Cleaner grouped model settings with consistent controls and light/dark colors.
- More conversational practice answers, clearer handling of multiple questions and fewer verbatim summaries.
- Fixes for unrelated project context in general knowledge questions and unsupported claims about a user's experience.
- Retrieval now works with ordinary uploaded material without a project label. Reimporting changed files invalidates stale cards so they can be distilled again.

### A clean start

No author knowledge base, project material, resume, interview history, credentials or configured model connections are included. Configure your own service in **AI & local data**, then import your own PDF, DOCX, code or notes. Import alone does not call a cloud model; AI distillation and answers use your configured service. Live transcription requires a compatible DashScope WebSocket configuration, not just a chat endpoint. No shared quota is provided.

### Validation

63 public-edition tests passed, including synthetic document import, retrieval and update tests with a model test double. All 878 runtime files match the source, and all 13,813 extracted installer payload files match the audited build. Empty first-run state and absent credentials were verified. The extracted application launched successfully, its home/settings screens were inspected, and bundled OCR recognized a Chinese scanned PDF.

In-place upgrades through the installer wizard and live cloud model/transcription calls were not tested in this release check. Existing user data is not automatically erased. Windows 10 / 11 x64; the installer is not signed with a trusted certificate. Use `SHA256SUMS.txt` to verify your download.
